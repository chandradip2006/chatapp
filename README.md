# chatapp
It is a real time chatting app.
there is no limit of persons that can connect through this chatting application
It uses web-socket to make the unintrrupted connection with the server and the client, not like the normal server-client model where the connection breaks between the server and client after one CRUD operation or sending or fetching some data to or from the server

It takes the input from one sender and it goes to the server and server emits the input message to all connected clients with minimum delay as output message and this makes a continuous connection between all the connected clients with the server at a particular time
